# FiJan

Το FiJan διαβάζει ένα αρχείο CSV χρονοδιαγράμματος και υπολογίζει τις άδειες (PTO) ανά εργαζόμενο και ανά εταιρεία. Αποθηκεύει τα αποτελέσματα ως CSV και PDF.

Αυτός ο οδηγός είναι για Windows 10. Δεν χρειάζεται να ξέρεις υπολογιστές — απλά ακολούθησε τα βήματα με τη σειρά.

---

## Μέρος 1 — Εγκατάσταση Python (μία φορά μόνο)

Το Python είναι το πρόγραμμα που τρέχει το FiJan στον υπολογιστή σου. Το εγκαθιστάς μία φορά.

### Βήμα 1: Κατέβασμα Python

1. Άνοιξε τον browser σου.
2. Πήγαινε στο: **https://www.python.org/downloads/**
3. Πάτα το κίτρινο κουμπί **Download Python install manager**.
4. Άνοιξε το αρχείο που κατέβηκε και ακολούθησε τις οδηγίες. Ο εγκαταστάτης κάνει τα περισσότερα μόνος του — δεν χρειάζεται να ανησυχείς.

### Βήμα 2: Προσθήκη Python στο PATH

Κάποια στιγμή θα ανοίξει ένα μαύρο παράθυρο (cmd) και θα σε ρωτήσει αν θέλεις να προστεθεί το Python στο PATH.

1. Πληκτρολόγησε **y**
2. Πάτα **Enter**

Αυτό επιτρέπει στον υπολογιστή να βρίσκει το Python από οπουδήποτε.

### Βήμα 3: Άνοιξε ξανά το cmd

**Κλείσε** το μαύρο παράθυρο αν είναι ακόμα ανοιχτό. Μετά:

1. Πάτα **Windows + R** στο πληκτρολόγιο.
2. Γράψε **cmd** και πάτα **Enter**.

Χρειάζεται νέο παράθυρο ώστε να «δει» ότι εγκαταστάθηκε το Python.

### Βήμα 4: Έλεγχος ότι δούλεψε

Στο μαύρο παράθυρο, γράψε αυτό και πάτα **Enter**:

```
python3 --version
```

Θα πρέπει να εμφανιστεί κάτι σαν `Python 3.12.7`.

- Αν το βλέπεις, είσαι έτοιμη. Μπορείς να κλείσεις το παράθυρο.
- Αν βγει σφάλμα, δοκίμασε ξανά το Βήμα 2 (γράψε **y** όταν σε ρωτήσει) και μετά ξανά το Βήμα 3.

## Μέρος 2 — Αποσυμπίεση του φακέλου FiJan

1. Κατέβασε ή αντιγράψε το zip του FiJan στον υπολογιστή σου.
2. Κάνε δεξί κλικ στο zip → **Extract All…** (Αποσυμπίεση όλων…)
3. Διάλεξε απλό μέρος, π.χ.: `C:\FiJan`
4. Μετά την αποσυμπίεση, θα έχεις έναν φάκελο **FiJan** με αρχεία μέσα (μεταξύ άλλων το `PTO_Calculator.py`).

Θυμήσου πού είναι ο φάκελος — θα τον χρειαστείς στο επόμενο μέρος.

---

## Μέρος 3 — Δημιουργία του FiJan.exe

Αυτά τα βήματα μετατρέπουν το FiJan σε ένα μόνο αρχείο (`FiJan.exe`) που ανοίγει με διπλό κλικ, χωρίς να ξαναγράφεις εντολές.

Άνοιξε ξανά το cmd:

1. Πάτα **Windows + R**, γράψε **cmd**, πάτα **Enter**.

2. Πήγαινε στον φάκελο FiJan. Γράψε αυτό (άλλαξε τη διαδρομή αν ο φάκελος είναι αλλού) και πάτα **Enter**:

   ```
   cd C:\FiJan
   ```

3. Δημιούργησε έναν ιδιωτικό χώρο για τα αρχεία του FiJan (μία φορά μόνο). Γράψε και πάτα **Enter**:

   ```
   python3 -m venv .venv
   ```

   Δεν θα γίνει κάτι ιδιαίτερο — είναι φυσιολογικό.

4. Ενεργοποίησε αυτόν τον χώρο. Γράψε και πάτα **Enter**:

   ```
   .venv\Scripts\activate
   ```

   Θα δεις `(.venv)` στην αρχή της γραμμής. Σημαίνει ότι δούλεψε.

5. Κατέβασε τις βιβλιοθήκες που χρειάζεται το FiJan. Γράψε και πάτα **Enter**:

   ```
   python3 -m pip install -r requirements-build.txt
   ```

   Περίμενε να τελειώσει. Μπορεί να πάρει ένα-δύο λεπτά.

6. Φτιάξε το exe. Γράψε και πάτα **Enter**:

   ```
   python3 scripts\build_exe.py
   ```

   Περίμενε μέχρι να δεις **Build finished.** Μπορεί να πάρει μερικά λεπτά.

7. Το exe είναι έτοιμο. Βρίσκεται εδώ:

   ```
   C:\FiJan\dist\FiJan.exe
   ```

   Άνοιξε την Εξερεύνηση αρχείων, πήγαινε στον φάκελο **FiJan**, μετά στον φάκελο **dist**. Θα δεις το **FiJan.exe**.

Μπορείς να κλείσεις το cmd τώρα.

## Μέρος 4 — Για το Νικάκι: βάλε το FiJan στην Επιφάνεια εργασίας

Όταν υπάρχει το **FiJan.exe**, **δεν** χρειάζεται Python ούτε cmd. Χρησιμοποιεί μόνο το exe.

### Δημιουργία συντόμευσης στην Επιφάνεια εργασίας

1. Άνοιξε την Εξερεύνηση αρχείων.
2. Πήγαινε στον φάκελο **dist** μέσα στο FiJan (εκεί που είναι το **FiJan.exe**).
3. **Δεξί κλικ** στο **FiJan.exe**.
4. Πάτα **Show more options** (Εμφάνιση περισσότερων επιλογών), αν εμφανιστεί, και μετά **Create shortcut** (Δημιουργία συντόμευσης).
   - Ή: δεξί κλικ στο **FiJan.exe** → **Send to** (Αποστολή σε) → **Desktop (create shortcut)** (Επιφάνεια εργασίας).
5. Πήγαινε στην Επιφάνεια εργασίας. Θα δεις μια συντόμευση με όνομα **FiJan.exe** ή **Shortcut to FiJan.exe**.
6. Προαιρετικά: δεξί κλικ στη συντόμευση → **Rename** (Μετονομασία) → γράψε **FiJan** → πάτα **Enter**.

### Πώς να χρησιμοποιεί το FiJan κάθε μέρα

1. Διπλό κλικ στη συντόμευση **FiJan** στην Επιφάνεια εργασίας.
2. Πάτα **Αναζήτηση** για να διαλέξεις το CSV χρονοδιαγράμματος.
3. Διάλεξε πού να αποθηκευτούν τα αποτελέσματα.
4. Πάτα **Υπολογισμός**.
5. Όταν τελειώσει, χρησιμοποίησε τα κουμπιά για να ανοίξεις τον φάκελο, το CSV ή το PDF.

### Αν εμφανιστεί προειδοποίηση ασφαλείας από τα Windows

Την πρώτη φορά που τρέχει το exe, τα Windows μπορεί να πούν **Windows protected your PC**. Είναι φυσιολογικό για εφαρμογές που δεν έχουν υπογραφή μεγάλης εταιρείας.

1. Πάτα **More info** (Περισσότερες πληροφορίες)
2. Πάτα **Run anyway** (Εκτέλεση παρ' όλα αυτά)

Μετά την πρώτη φορά, συνήθως ανοίγει κανονικά.

## Σύντομη περίληψη

| Ποιος | Τι κάνει |
|-------|----------|
| **Εσύ (ρύθμιση, μία φορά)** | Εγκατάσταση Python → αποσυμπίεση FiJan → οι 6 εντολές στο Μέρος 3 → παίρνεις `dist\FiJan.exe` |
| **Το Νικάκι (κάθε μέρα)** | Διπλό κλικ στη συντόμευση στην Επιφάνεια εργασίας → διάλεξε CSV → Υπολογισμός |
